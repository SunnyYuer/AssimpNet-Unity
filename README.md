## 介绍 ##
这是基于[AssimpNetter](https://github.com/Saalvage/AssimpNetter)和[assimpnet-unity](https://github.com/intelligide/assimpnet-unity)开发的适用于Unity的AssimpNet，用来动态导入导出3D模型。

## 平台支持情况 ##
* **Unity**
	* Unity2018.1+, .NET Standard 2.0 (在Unity2019.4测试通过)
* **Windows**
	* x64 (在Win10测试通过)
* **Linux**
	* x64 (在OpenSUSE15.6测试通过)
* **MacOS**
	* x64 (未知，AssimpNetter那边都测试通过了，应该没问题吧？)
* **Android**
	* Android7.0+ (在安卓15模拟器测试通过)
* **iOS**
	* 不支持，封闭环境没法读取外部文件，欢迎大佬提交支持

## 项目编译 ##
Visual Studio 2022+
